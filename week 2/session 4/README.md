# ACCESS 7.0 – Week 2, Session 4
## Working with Data Using NumPy and Pandas

### Session Overview

In this session, we move from learning Python fundamentals to working with structured datasets.

We will explore two important Python libraries used in Data Science: NumPy and Pandas. Students will learn how to create and manipulate numerical arrays, understand Pandas Series and DataFrames, load datasets from CSV and Excel files, and retrieve information by inspecting, selecting and filtering data.

The session will use practical examples and the Sample Superstore dataset to demonstrate how these tools are applied to real-world data.

### Learning Objectives

By the end of this session, students should be able to:

- Explain what NumPy and Pandas are and why they are useful in Data Science.
- Create NumPy arrays and perform basic numerical operations.
- Understand the difference between one-dimensional and multi-dimensional arrays.
- Explain the difference between a Pandas Series and a DataFrame.
- Load CSV and Excel datasets into Python.
- Inspect datasets using common Pandas methods.
- Select specific columns and filter rows based on conditions.
- Apply basic NumPy operations to numerical data from a Pandas DataFrame.
- Save and share their Jupyter notebooks using GitHub.

### Topics Covered

**1. Introduction to NumPy**
- What NumPy is and its applications.
- Creating NumPy arrays.
- Array dimensions and shape.
- Accessing array elements.
- Basic numerical operations and statistical functions.

**2. Introduction to Pandas**
- What Pandas is and why it is useful.
- Understanding Pandas Series.
- Understanding Pandas DataFrames.
- Creating simple DataFrames.

**3. Loading Datasets**
- Understanding CSV and Excel file formats.
- Loading datasets using `pd.read_csv()` and `pd.read_excel()`.

**4. Inspecting Datasets**
- Viewing the first and last rows using `head()` and `tail()`.
- Checking dataset dimensions using `shape`.
- Viewing column names using `columns`.
- Understanding data types and dataset structure using `info()`.
- Generating descriptive statistics using `describe()`.

**5. Selecting and Filtering Data**
- Selecting individual columns.
- Selecting multiple columns.
- Selecting rows using `iloc`.
- Filtering rows using conditions.
- Combining multiple filtering conditions.
- Sorting records using `sort_values()`.

**6. Working with NumPy and Pandas Together**
- Converting Pandas columns into NumPy arrays.
- Performing numerical calculations on dataset values.
- Creating new columns using calculations.

**7. GitHub and Notebook Sharing**
- Accessing an existing GitHub repository.
- Uploading the Session 4 notebook.
- Committing changes and sharing repository links.

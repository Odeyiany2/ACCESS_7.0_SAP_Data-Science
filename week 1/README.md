## 3. Your Assignment: Think Like a Data Scientist

Choose a real-world problem or situation in a field that interests you.

It could be related to education, agriculture, healthcare, finance, transportation, business, technology or any other area.

Answer the following questions:

1. What problem would you like to understand or solve?
2. Why is this problem important?
3. What three questions would you ask to understand the problem better?
4. What three types of data would help you investigate it?
5. How could the data help someone make a better decision?

**Important:** You do not need to write any code for this assignment.

The goal is to practise thinking about problems, asking meaningful questions and identifying the kinds of data that could help answer them.

Estimated completion time: 30–45 minutes.

Follow the submission instructions and deadline communicated by the programme organisers.

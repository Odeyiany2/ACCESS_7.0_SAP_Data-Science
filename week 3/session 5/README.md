# Session 5: Understanding Data Quality

**Course:** Introduction to Data Science with Python: From Data to Insights  
**Programme:** ACCESS 7.0  
**Session:** 5  
**Duration:** 2 hours

## Session Overview

In this session, students learn how to identify and investigate data-quality problems before using a dataset for analysis.

Using a deliberately messy version of the Sample Superstore dataset, students explore common issues such as missing values, duplicate records, inconsistent categories, incorrect data types, inconsistent date formats and invalid values.

The focus is on understanding and detecting these problems, examining their potential impact, and recommending appropriate next steps. Students will not carry out the full cleaning process in this session; that will be covered in Session 6.

## Learning Objectives

By the end of this session, students should be able to:

- Explain what data quality means and why it matters.
- Identify common data-quality issues in a dataset.
- Use Pandas to investigate missing values and duplicates.
- Recognise inconsistent categories and incorrect data types.
- Identify inconsistent date formats and potentially invalid values.
- Explain how poor data quality can affect analysis and decision-making.
- Document data-quality findings and recommend appropriate actions.

## Topics Covered

1. Introduction to data quality and its importance.
2. Dimensions of data quality: completeness, accuracy, consistency, validity and uniqueness.
3. Identifying missing values.
4. Detecting duplicate records.
5. Identifying inconsistent categories and text.
6. Understanding incorrect data types.
7. Investigating inconsistent and invalid date formats.
8. Identifying values that may violate business rules.
9. Conducting a basic data-quality audit.

## Tools and Resources

- Python
- Google Colab
- Pandas
- NumPy
- Messy Superstore dataset (`Messy_Superstore.csv`)

## Practical Activities

Students will work through the messy Superstore dataset and use Pandas to investigate different data-quality issues.

They will inspect the dataset, identify affected columns and records, gather evidence of problems, and discuss how these issues could affect analysis.

Students will also complete a guided data-quality audit.

## Assignment: Data Quality Audit

Students are required to conduct an initial data-quality audit of the messy Superstore dataset.

The assignment involves:

- Inspecting the dataset's structure and data types.
- Investigating missing values, duplicates, inconsistent categories, incorrect data types, date issues and invalid values.
- Documenting at least five identified data-quality issues.
- Explaining the potential impact of each issue.
- Recommending appropriate next steps.
- Reflecting on why data quality matters before analysis.

**Submission format:** Google Colab notebook (`.ipynb`)

**Filename:** `Session_5_Data_Quality_Audit_Assignment.ipynb`

Students should upload their completed notebook to their ACCESS 7.0 GitHub repository and submit the repository link using the designated class submission sheet.

**Estimated completion time:** 45–60 minutes.

## Connection to the Next Session

Session 6 will build directly on this session. Students will return to the same messy dataset and learn how to address the issues they identified through practical data-cleaning and preparation techniques.

They will work with missing values, remove genuine duplicates, standardise text, convert data types, parse dates and validate their cleaning decisions.

**Session 5 focuses on identifying and understanding data-quality problems. Session 6 focuses on addressing and validating them.**

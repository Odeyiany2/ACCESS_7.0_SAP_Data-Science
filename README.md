# Introduction to Data Science with Python: From Data to Insights

Welcome to the **ACCESS 7.0 Data Science Programme!** 🎉

This repository contains the learning resources, practical notebooks, datasets, assignments and project materials for our eight-week Introduction to Data Science programme.

Whether you're studying Accounting, Business, Computer Science, Engineering, Agriculture, Health Sciences or any other discipline, this programme will help you understand how to work with data, uncover insights and use evidence to support better decisions.

**No prior programming or Data Science experience is required.** We'll learn step by step, with plenty of practical exercises along the way.

---

## About the Programme

Data is generated in almost every field. But collecting data is only the beginning. The real value comes from knowing how to ask the right questions, analyse information, identify patterns and communicate what those patterns mean.

Throughout this programme, we'll explore the Data Science process using Python and practical datasets.

By the end of the programme, you'll be able to:

- Understand the Data Science lifecycle and how it applies to real-world problems.
- Write basic Python code and work with data using Pandas and NumPy.
- Clean and prepare datasets for analysis.
- Explore datasets and identify meaningful patterns.
- Create visualisations and communicate insights effectively.
- Understand the fundamentals of Machine Learning.
- Build and evaluate simple predictive models.
- Complete a practical Data Science project relevant to a problem or field of interest.

### What about C and C++?

C and C++ are also important in the broader Data Science and computing ecosystem. Although Python is commonly used for data analysis and Machine Learning, C and C++ are widely used in areas where performance, memory management and efficient computation are important.

Here are some examples:

| Area | Library / Technology | Application |
|---|---|---|
| Numerical Computing | NumPy (C API) | Supports lower-level access to NumPy arrays and extensions. |
| Machine Learning | PyTorch (LibTorch) | Building and running neural networks directly with C++. |
| Machine Learning | XGBoost | Provides C++ interfaces for gradient-boosting algorithms. |
| Computer Vision | OpenCV | Image processing, object detection and computer vision applications. |
| Data Engineering | Apache Arrow | Efficient in-memory data representation and processing. |
| High-Performance Computing | CUDA C++ | Using GPUs to accelerate computationally intensive tasks. |

Some examples worth exploring:

- [NumPy](https://numpy.org/doc/stable/reference/c-api/) – C API documentation.
- [PyTorch C++ API](https://docs.pytorch.org/cppdocs/) – Machine Learning with C++.
- [XGBoost](https://xgboost.readthedocs.io/) – Gradient-boosting library.
- [OpenCV](https://opencv.org/) – Computer vision library.
- [Apache Arrow](https://arrow.apache.org/docs/cpp/) – High-performance data processing.

**An important distinction:** You can use a Python library without writing C or C++ yourself. Some Python libraries use lower-level languages internally to make their operations more efficient. Others also provide interfaces that allow developers to work with them directly in C or C++.

### What about R?

R is another popular language, particularly for statistical analysis, data visualisation and research. It is widely used in fields such as statistics, economics, healthcare and academic research.

We'll focus on Python in this programme, but understanding that other languages exist and have different strengths is part of becoming a well-rounded Data Science practitioner.

**The key takeaway:** You don't need to know every programming language to work in Data Science. What matters is understanding the problem, knowing how to work with data and choosing the right tools to solve it.

## Final Project

The programme concludes with a practical Data Science project.

You'll identify a problem or question relevant to a field of interest, find a suitable dataset, analyse the data and communicate your findings.

Your project should demonstrate your ability to:

- Define a meaningful problem.
- Identify and source an appropriate dataset.
- Prepare and explore the data.
- Communicate findings through visualisations and explanations.
- Draw conclusions and make evidence-based recommendations.
- Discuss limitations and responsible use of data.

Machine Learning can be included where it is appropriate for the problem.

## Responsible Data Use

As we learn to work with data, we'll also learn to handle it responsibly.

Please:
- Use datasets that are publicly available or that you have permission to use.
- Avoid uploading confidential or personally identifiable information.
- Respect dataset licences and attribution requirements.
- Interpret results carefully and acknowledge limitations.

## A Few Things to Remember

- You do not need to know how to code before joining.
- Ask questions whenever something is unclear.
- Practise outside the sessions.
- Don't be afraid to experiment and make mistakes.
- Focus on understanding what your analysis means, not just getting your code to run.
